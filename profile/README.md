## Four Beats

1. **Name the sheet.** Give the FluidSIM session a short title before you edit the pneumatic circuit.
2. **Pin the live valves.** Keep current cylinders and plots on the FluidSIM board and leave unused parts aside.
3. **Check the plot.** Read the FluidSIM summary of the simulation plot before you treat a lab schematic as final.
4. **Close the loop.** Note which plots are ready so the next FluidSIM visit does not start by hunting the hydraulic model.

## First Questions

**Does FluidSIM replace the paper lab sheet?**  
No. FluidSIM sits beside the notebook and the fluid circuits you already draw in class.

**Can two students share one computer?**  
Yes. Each person keeps a separate FluidSIM profile for their own lab schematic.

**Will FluidSIM stay workable on an older lab laptop?**  
Yes. FluidSIM is meant to stay light during a normal class session.

**What should a new user try first?**  
One small FluidSIM pneumatic circuit today, then the same simulation plot again tomorrow.

## Field Note

FluidSIM is easier to trust when the schematic stays smaller than the bench it came from. A named session shows which lab is active, the pins show which valves you will move today, and the closing note tells the next person which pneumatic circuit drives the simulation plot. That record is short on purpose: not a copy of every cylinder, only the path back to the lab schematic that is still open.

The same loop fits a student pneumatic bench, a client hydraulic block, or a computer shared by two students. Open the last FluidSIM session, confirm one plot, and leave the pressures easier to read than you found them. Notebooks stay where they are. FluidSIM only holds the pneumatic circuit, the hydraulic model, and the handoff.

## One Real Pass

Pick a fluid circuit that already has a name: a short pneumatic loop, a hydraulic press sheet, or a mixed class exercise. Open it in FluidSIM, keep only those valves on the board, and read one simulation plot you can point to. A pass is done when that plot stays tied to the lab schematic and the unused parts are no longer in the way. FluidSIM does not need a full rebuild of the sheet before it is useful.

If the pass feels crowded, the sheet is too wide. Drop anything that belongs to a different class and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first valve to the last plot, with the summary still matching the lab schematic on the board.
